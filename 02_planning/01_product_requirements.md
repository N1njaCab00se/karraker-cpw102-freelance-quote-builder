# Product Requirements

**Team members:**

Translate the designer's description into requirements. Keep answers brief.

## User and goal

**Who will use this program?**
The freelancer themself.

**What problem will it help them solve?**
How much the freelancer's services will cost a client, determining a certain amount of time.

## Requirements

Write each requirement as “The program must…” in your own words. Cover the inputs, calculations, name cleanup, and displayed estimate. Make each statement specific enough to check. Add numbered items as needed.

1. The program must ask for four separate lines. Client name, Estimated hours, hourly rate, and direct expenses.
2. The program must calculate the estimated hours times the hourly rate, plus direct expenses, to come up with a total number.
3. The program must format the client's name to a clean-looking format. EX; AlEx TaYlOr will become Alex Taylor.

## Success

**What should the user be able to do when the program works?**
Give a client a quote on about how much a certain project will cost.
